# Como contribuir

Obrigado por querer ajudar o **Banking Frontend Challenge BR**! Toda contribuição conta.

## Formas de contribuir

- **Enviar sua solução:** abra uma issue com o formulário [Enviar minha solução](https://github.com/guubernardi/Banking-Frontend-Challenge-BR/issues/new?template=enviar-solucao.yml). Ela entra no mural do README.
- **Sugerir telas ou fluxos:** tem uma ideia (Open Finance, investimentos, cartão virtual)? Abra uma issue contando o fluxo.
- **Melhorar o README:** textos mais claros, correções, exemplos de mocks em JSON.
- **Traduzir:** versões do README em outros idiomas são bem-vindas.

## Enviando um pull request

1. Faça um fork do repositório
2. Crie uma branch: `git checkout -b minha-melhoria`
3. Faça suas alterações e um commit com uma mensagem clara
4. Abra o pull request explicando o que mudou e por quê

## Boas práticas

- Escreva em português (exceto traduções)
- Mantenha o tom acolhedor: o desafio é pensado para quem está começando
- Uma mudança por pull request deixa a revisão mais rápida
